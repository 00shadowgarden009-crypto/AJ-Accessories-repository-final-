# AJ ACCERSSORES

A premium, full-stack e-commerce platform for AJ ACCERSSORES.

## Development setup

1. Copy `.env.example` to `.env.local`.
2. Add Supabase project values.
3. Install dependencies: `npm install`.
4. Start locally: `npm run dev`.

Supabase service-role credentials must never be exposed in browser code or committed to Git.
